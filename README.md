# Face Detection Using Python and OpenCV

## Project Overview
This project is a simple face detection application developed using Python and OpenCV. It uses a camera to detect human faces in real time and displays a green rectangle around each detected face.

The main goal of this project is to understand the basics of computer vision and learn how face detection works.

## Features
- Detects human faces through a camera.
- Displays a green rectangle around detected faces.
- Processes the camera feed in real time.
- Demonstrates basic computer vision using OpenCV.

## Technologies Used
- Python
- OpenCV

## How It Works
1. The application accesses the camera.
2. It captures video frames continuously.
3. OpenCV processes the frames to detect faces.
4. When a face is detected, a green rectangle is drawn around it.
5. The camera window can be closed to stop the application.

## Installation

Install Python on your system, then install OpenCV using:

```bash
pip install opencv-python
```

## How to Run
1. Clone or download this repository.
2. Open the project folder in your code editor.
3. Run the Python file:

```bash
python face_detection.py
```

Replace `face_detection.py` with the actual name of your Python file if it is different.
